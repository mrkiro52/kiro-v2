# ML-0 Идеи внедрения ML в текущую платформу

**Команда:** ML · **Исполнитель:** вся ML-команда (ведущий — ML-лид) · **Старт:** **сразу**

## Зачем
Прежде чем планировать ML в v2.0, нужно, чтобы ML-команда вместе посмотрела на текущую платформу, обсудила, где ML может реально помочь студентам и кураторам, и выбрала пару лучших идей. Задача — не исследование и не прототип, а общее обсуждение и короткое предложение.

## Что нужно на входе
- Текущая платформа v1: зайти как студент и пройти основные разделы (программы, курсы, домашки, SQL-тренажёр, соцсеть, вакансии)
- Репозиторий v1: https://github.com/mrkiro52/platform — по желанию `docs/ML_AI_OPPORTUNITIES.md` (уже собранные идеи) и `backend/src/db.js` (какие данные есть)

## Что сделать
1. Каждый участник заранее смотрит платформу и приносит 2–3 идеи, где можно применить ML.
2. Провести общую встречу команды (1–1,5 часа): каждый коротко рассказывает свои идеи, обсуждаете вместе.
3. Собрать общий список идей (5–10 штук) — одной строкой на идею: что делаем и кому помогает.
4. Вместе выбрать 2–3 лучшие идеи (по пользе для студентов/кураторов и реальности реализации).
5. Для каждой топ-идеи тезисно описать, как планируете реализовать:
   - какую проблему решаем и для кого;
   - какие данные нужны и есть ли они сейчас;
   - подход (готовая модель / LLM / своя модель) и примерная схема работы;
   - как встроить в платформу (где пользователь это увидит);
   - как поймём, что работает (1–2 метрики);
   - риски и ограничения (качество, стоимость, персональные данные).
6. Оформить результат одним документом и коротко показать продакт-владельцу.

## Что должно получиться
- `docs/ml/ideas.md`: список всех идей + 2–3 топ-идеи с тезисами реализации (по пунктам из шага 5)

## Критерии готовности
- [ ] Встреча ML-команды проведена, в обсуждении участвовали все
- [ ] Есть список из 5–10 идей
- [ ] Выбраны 2–3 топ-идеи, по каждой есть тезисы реализации
- [ ] Учтено: данные студентов — только обезличенные, во внешние LLM — без идентификаторов (152-ФЗ)
- [ ] Документ показан продакт-владельцу
