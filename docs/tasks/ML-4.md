# ML-4 Прототипы топ-3 идей

**Команда:** ML · **Исполнитель:** ML-разработчики · **Старт:** после ML-2 (#38), ML-3 (#39)

## Зачем
Проверить топ-3 идеи на обезличенных данных, прежде чем встраивать их в платформу.

## Что нужно на входе
- ML-2 (топ-3 и метрики)
- ML-3 (правила и обезличенные данные)

## Что сделать
1. Для каждой идеи собрать минимальный прототип (ноутбук или простой сервис).
2. Измерить метрику из ML-2 на обезличенных данных или ручной разметке.
3. Оценить стоимость (вызовы LLM, инфраструктура) и риски ошибок.
4. Показать прототипы кураторам и продакт-владельцу, собрать обратную связь.
5. Рекомендовать: внедрять / дорабатывать / отказаться.

## Что должно получиться
- Код прототипов в `services/ai/prototypes/`
- `docs/ml/prototypes-report.md`

## Критерии готовности
- [ ] Для каждой идеи есть измеренная метрика и рекомендация.
- [ ] Соблюдены правила ML-3.
- [ ] Отчёт обсуждён с продакт-владельцем.

## С кем согласовать
Продакт-владелец, ИБ (SEC)

## Вне объёма
Встраивание в продакшен — после решения по отчёту.

> Места, помеченные «предложение» или «предложить», — рекомендации, которые исполнитель проверяет и подтверждает с владельцем решения.
