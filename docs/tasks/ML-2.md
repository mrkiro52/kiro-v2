# ML-2 Приоритизация идей по RICE и выбор топ-3

**Команда:** ML · **Исполнитель:** ML-лид · **Старт:** после ML-0 (#35), ML-1 (#37)

## Зачем
Нужно выбрать, на какие идеи потратить силы, по фактам из ML-0 и ML-1, а не по ощущениям.

## Что нужно на входе
- ML-0 (идеи и предварительный RICE)
- ML-1 (боли из интервью)

## Что сделать
1. Обновить карточки идей с учётом интервью.
2. Пересчитать RICE: охват (сколько студентов/кураторов затронет за поток), влияние, уверенность (есть ли данные и подтверждение в интервью), трудоёмкость.
3. Обсудить топ-5 с продакт-владельцем и выбрать топ-3.
4. Для каждой из топ-3 описать гипотезу и метрику успеха.

## Что должно получиться
- `docs/ml/rice.md` (финальная версия)
- `docs/ml/top-3.md`

## Критерии готовности
- [ ] Топ-3 утверждён продакт-владельцем.
- [ ] У каждой идеи есть гипотеза и измеримая метрика.
- [ ] Решение оформлено как ADR.

## С кем согласовать
Продакт-владелец, ИБ (по данным)

## Вне объёма
Прототипы — ML-4.
