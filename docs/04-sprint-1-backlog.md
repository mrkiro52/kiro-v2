# Спринт 1: авторизация, регистрация, соцсеть

**Цель продукта (после спринта 1 и этапов 2–3):** регистрация и вход, профиль (аватар, «о себе», ссылки, приватность), посты, комментарии, ответы на комментарии, лайки на посты и комментарии, лента и посты пользователя.

## Как устроена работа

- Четыре команды стартуют одновременно, у каждой есть задачи без зависимостей (метка `start-now`).
- Каждая команда идёт по своей очереди; между командами нет блокирующих зависимостей. Результаты соседей учитываются, когда появляются (раздел «Параллельные входы» в задаче).
- Объём спринта, перечисленный выше, — общая точка опоры: по нему можно начинать проектирование, не дожидаясь пользовательских историй.
- Точки синхронизации: раз в неделю короткая встреча команд (15–30 минут), где сверяют допущения и правят документы.
