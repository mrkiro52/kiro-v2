# Дизайн

Единый источник стилей KIRO Platform — [kiro-design-system.md](kiro-design-system.md): цвета, шрифты, отступы, радиусы, тени, CSS-переменные и компоненты (Button, Badge, Widget, Input, NavItem, SegmentTabs, Banner).

Правила:
- Фронтенд, админка и макеты в Figma берут токены только из этого файла; свои цвета и размеры не добавляем.
- Если нужен новый токен или компонент — предложи изменение через PR в `docs/design/kiro-design-system.md`.
- Исходник файла находится в репозитории v1 (`docs/kiro-design-system.md`); после переезда актуальная версия — здесь.
