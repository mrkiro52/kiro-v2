## Кандидаты идей
1. Черновик проверки развёрнутых ответов (LLM)
2. Эталонные ответы и рубрики
3. Поиск списывания
4. RAG-ассистент по материалам
5. Рекомендации «что повторить»
6. Генерация задач
7. Риск отвала
8. Подбор вакансий

- ML-команде — только обезличенная выгрузка.
- Ответы во внешние LLM — без идентификаторов.
