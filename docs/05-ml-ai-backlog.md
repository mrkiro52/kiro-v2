# ML/AI

**Состав:** ML (лид) и ML-разработчики; бизнес-аналитик, ИБ и фуллстак — по запросу.

## Задача
Одна задача на всю ML-команду: [ML-0 Идеи внедрения ML в текущую платформу](tasks/ML-0.md) ([#35](https://github.com/mrkiro52/kiro-v2/issues/35)).
Команда вместе обсуждает идеи, выбирает 2–3 лучшие и тезисно описывает, как их реализовать. Дальнейшие задачи (прототипы, данные) заводятся после обсуждения результатов.

## Кандидаты идей (для затравки обсуждения)
1. Черновик проверки развёрнутых ответов (LLM)
2. Эталонные ответы и рубрики
3. Поиск списывания
4. RAG-ассистент по материалам
5. Рекомендации «что повторить»
6. Генерация задач
7. Риск отвала
8. Подбор вакансий

## Ограничения по данным (152-ФЗ)
- ML-команде — только обезличенная выгрузка.
- Ответы во внешние LLM — без идентификаторов.
- Исходный анализ идей: `docs/ML_AI_OPPORTUNITIES.md` в репозитории v1.
