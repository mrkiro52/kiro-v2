# ML/AI

**Состав:** ML (лид) и ML-разработчики; бизнес-аналитик, ИБ и фуллстак — по запросу.

## Задача
Одна задача на всю ML-команду: [ML-0 Идеи ML для авторизации, регистрации и соцсети v2.0](tasks/ML-0.md) ([#35](https://github.com/mrkiro52/kiro-v2/issues/35)).
Сейчас в v2.0 делаются авторизация, регистрация, профили и соцсеть (посты, комментарии, ответы, лайки, лента), поэтому идеи ищем для этого функционала. Команда вместе обсуждает идеи, выбирает 2–3 лучшие и тезисно описывает реализацию.

## Варианты для размышления
- Проверка логинов и никнеймов (мат, скрытые значения, транслит, замена букв)
- Спам / не спам в комментариях и постах
- Модерация контента и приоритизация жалоб
- Автотеги и категоризация постов
- Рекомендации «кого читать» и «похожие посты»
- Генерация и ассистент (простой Т9, автодополнение)
- Умный поиск по постам (по смыслу, а не по подстроке)

Идеи для учебной части платформы (проверка домашек, RAG по материалам, риск отвала и т.д.) — на потом, см. `docs/ML_AI_OPPORTUNITIES.md` в репозитории v1.

## Ограничения по данным (152-ФЗ)
- ML-команде — только обезличенная выгрузка.
- Ответы во внешние LLM — без идентификаторов.
