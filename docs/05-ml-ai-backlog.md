# ML/AI: рабочая группа на 2 недели

**Состав:** ML (лид), продуктовый, системный и бизнес-аналитик; ИБ и фуллстак — по запросу.

## Задачи
**ML-0** (можно начинать сразу): [изучить платформу v1 и подготовить идеи](tasks/ML-0.md) — вход для ML-1…ML-5.

| ID | Задача | Результат |
|---|---|---|
| ML-1 | Интервью с кураторами и студентами | Список болей и сценариев |
| ML-2 | Сбор и описание кандидатов идей | Карточки идей (проблема, данные, риск) |
| ML-3 | Приоритизация по RICE | Таблица Reach / Impact / Confidence / Effort |
| ML-4 | Требования к данным и приватности | Правила выгрузки и работы с LLM |
| ML-5 | Топ-3 идеи в прототип | Описание прототипов, критерии успеха |

## Кандидаты идей
1. Черновик проверки развёрнутых ответов (LLM)
2. Эталонные ответы и рубрики
3. Поиск списывания
4. RAG-ассистент по материалам
5. Рекомендации «что повторить»
6. Генерация задач
7. Риск отвала
8. Подбор вакансий

## Ограничения по данным (152-ФЗ)
- ML-команде — только обезличенная выгрузка.
- Ответы во внешние LLM — без идентификаторов.
- Исходный анализ идей: `docs/ML_AI_OPPORTUNITIES.md` в репозитории v1.
